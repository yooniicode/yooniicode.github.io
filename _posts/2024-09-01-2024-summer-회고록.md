- **PicoPitch**
  UMC 6기 server 파트장으로 한 학기 반을 불태웠고 프로젝트까지 예쁘게 끝날 줄 알았으나 정말정말 고되었다
  매주 반복되는 전체 회의에 계속되는 개발 압박까지는 즐거웠고 뿌듯했다
  API 개발 및 명세서 제공을 다 한 상태로, 프론트엔드 분들이 연동해주시기를 기다렸다
  코틀린 개발은 잘 모르기에(TS만 해봤다) 마지막에 하실 것 같아서 마냥 기다렸는데
  알고보니 전체 회의 프론트엔드 팀의 진행 상황 보고는 거짓이였고… 그 내용을 데모데이 영상 제출 당일 알아버렸다
  PM 분들도, 백엔드도 당황스러웠고 결국 데모데이는 무산되었으나 
  그래도 백엔드 팀장으로 열심히 해왔던 경험은 소중하게 가지고 갈 것 같다
  PM 분들 중 전 기수에서 노드 파트로 계셨던 분들 덕분에 큰 걱정 없이 진행할 수 있었고(감사합니다),
  특히 백엔드 팀에서 `스프린트 + 데일리 스크럼 ❤️` 을 하면서 많이 늘었는데,
  매일매일 진행상황 공유하고 새벽에도 열정적으로 개발하는 팀원들 보면서 많이많이 자극받았다
  매주 한두번씩 사당역에서 만나가면서 스프린트 기간 가진 것도 도움이 된 것 같다
  팀원들 깃 가르쳐주면서 내 깃 실력도 같이 느는 모습을 볼 수 있었다
  다시 볼 수 있기를!…

- **홀로서기**
  PM으로, 디자인으로, 그리고 프론트엔드 포지션으로 참여한 소중한 프로젝트였다!
  온전한 PM으로서 꼼꼼한 절차를 밟진 못했으나 그래도 아이디어나 화면설계서까지 제출했었고
  디자인으로 피그마 화면 만들어가면서, 프엔분들과 업무 분담해서 화면 만들고 API 연동했다! 
  CSS와 HTML로 개발했었는데 TypeScript로 전부 변경해서 진행했었고 그부분에서 TS의 편리성도 알아가고
  스프링부트 서버분들과 함께 진행했었어서 프로젝트 돌아가는 플로우도 조금이나마 더 안 것 같다
  사실 서버 분야가 하고 싶어서, 프론트도 조금이나마 알면 더 도움이 되지 않을까 싶어서 경험해보게 되었는데
