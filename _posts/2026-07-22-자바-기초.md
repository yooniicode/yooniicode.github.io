# Day 1

- 절차 지향은 데이터와 해당 데이터에 대한 처리 방식이 분리되어 있다. 
- 반면 객체 지향에서는 데이터와 그 데이터
에 대한 행동(메서드)이 하나의 '객체' 안에 함께 포함되어 있다.

- 각 기능을 메서드로 만들어 객체 Class 내부에 포함하게 되는 경우
  - 로직 중복 제거
  - 변경 영향 범위 (메서드 내부만 변경하면 됨)
  - 메서드 이름 추가 

- `static`은 객체 내부 메서드 정의 시 사용하지 않는다. `static`이 붙으면 객체를 생성하지 않고도 메서드를 호출할 수 있다.

### 캡슐화
- 속성과 기능을 하나로 묶어 필요한 기능을 메서드를 통해 외부에 제공하는 것
  - 가독성
  - 코드 변경의 용이함
    - 외부 호출부를 변경하지 않아도 됨 (메서드 이름 변경 제외)
